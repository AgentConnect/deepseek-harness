# AWiki

English | [中文](README.zh.md)

AWiki integration packages provide one deployment identity and transport-protected direct, existing-group, history, and attachment messaging. [`awiki/`](awiki/README.md) owns `ctx.awiki`, the TypeScript SDK provider, the browser Remote, and model tools.
